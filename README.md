# NeuroPilot Core

A likely-forever experiment with separating NeuroPilot's core from the Neuro API "frontend".

This project is not affiliated with the main NeuroPilot VS Code extension, which can be found [here](https://github.com/VSC-NeuroPilot/neuropilot)

## Motivation (why bother?)

One of my main uses for GitHub Copilot is to show me where certain key symbols, like functions or classes, are defined or used. I liked the idea of additional tools but didn't want to have to make it rigidly comply with VS Code API requirements. Plus, I always wanted to do this anyways to make it easier to interoperate with other agents I might use, and some other features of NeuroPilot I thought could be legitimately neat.

## Will this ever be moved to the VSC-NeuroPilot org (seeing as you're one of the members)?

Likely not. NeuroPilot is quite tightly tied together right now, so it will take a while to decouple fully, at which point either I've lost motivation on separation, or I become too busy to actually make progress.
If it does get moved though, I wouldn't complain. Modularity can be fun.

## Could I use this extension too?

Absolutely; however be aware that I provide no guarantees about the stability of this extension right now. I'll try, at least.
